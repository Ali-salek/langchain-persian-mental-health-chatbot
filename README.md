# 🧠 سامانه محرمانه سلامت روان (چت‌بات فارسی با LangChain)

یک دستیار گفتگوی فارسی برای حمایت از سلامت روان و مدیریت استرس همکاران یک سازمان. این پروژه با **Streamlit**، **LangChain** و **Redis** ساخته شده و علاوه بر نگه‌داشتن تاریخچه‌ی گفتگو، به‌صورت خودکار **خلاصه‌ی تدریجی** از مکالمات قدیمی می‌سازد تا مدل همیشه زمینه‌ی کامل گفتگو را داشته باشد، بدون اینکه حجم پرامپت بی‌نهایت بزرگ شود.

## ✨ امکانات

- رابط کاربری چت فارسی با Streamlit
- ذخیره‌ی تاریخچه‌ی گفتگوی هر کاربر در Redis
- **حافظه‌ی ترکیبی**: ۵ پیام اخیر به‌صورت کامل + خلاصه‌ی پیام‌های قدیمی‌تر
- خلاصه‌سازی افزایشی (Incremental) با استفاده از یک اشاره‌گر (Cursor) که مشخص می‌کند تا کدام پیام خلاصه شده است
- نمایش خلاصه‌ی گفتگو و مرور سریع پیام‌ها در سایدبار
- پرامپت سیستمی که در مواقع بحران، کاربر را به متخصص انسانی ارجاع می‌دهد
- استفاده از مدل‌ها از طریق [OpenRouter](https://openrouter.ai)

## 🏗️ معماری

```
پیام کاربر
    │
    ▼
┌──────────────────────────────────────────┐
│ پرامپت = پرامپت سیستمی                    │
│        + خلاصه‌ی گفتگو (از Redis)          │
│        + ۵ پیام اخیر (از Redis)            │
│        + پیام جدید                        │
└──────────────────────────────────────────┘
    │
    ▼
 مدل زبانی  ──►  پاسخ  ──►  ذخیره در Redis
                               │
                               ▼
                    پیام‌های قدیمی‌تر از ۵ پیام اخیر
                    با مدل خلاصه‌ساز ادغام می‌شوند
```

| کلید Redis | کاربرد |
|---|---|
| `salamat:chatwithhistory:<user>` | تاریخچه‌ی پیام‌های کاربر |
| `salamat:summary:<user>` | خلاصه‌ی فعلی گفتگو |
| `salamat:cursor:<user>` | اندیس آخرین پیامِ خلاصه‌شده |

## 🧰 پیش‌نیازها

- Python 3.10 یا بالاتر
- Docker و Docker Compose (برای اجرای Redis)
- یک کلید API از [OpenRouter](https://openrouter.ai/keys)

## 🚀 نصب و اجرا

**۱. کلون کردن پروژه**

```bash
git clone https://github.com/Ali-salek/langchain-persian-mental-health-chatbot.git
cd langchain-persian-mental-health-chatbot
```

**۲. نصب وابستگی‌ها**

```bash
pip install streamlit redis langchain-openai langchain-core langchain-community
```

**۳. اجرای Redis**

```bash
docker compose up -d
```

**۴. تنظیم متغیرهای محیطی**

Linux / macOS:

```bash
export OPENROUTER_API_KEY="your-key-here"
export REDIS_URL="redis://localhost:6379/0"
```

Windows (PowerShell):

```powershell
$env:OPENROUTER_API_KEY="your-key-here"
$env:REDIS_URL="redis://localhost:6379/0"
```

**۵. اجرای برنامه**

```bash
streamlit run appwithsummarizer.py
```

سپس آدرس `http://localhost:8501` را در مرورگر باز کنید.

## ⚙️ تنظیمات

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `OPENROUTER_API_KEY` | — | کلید API سرویس OpenRouter (الزامی) |
| `REDIS_URL` | `redis://localhost:6379/0` | آدرس اتصال به Redis |

داخل کد می‌توانید مقادیر زیر را تغییر دهید:

- `MAX_RECENT`: تعداد پیام‌های اخیری که کامل به مدل داده می‌شوند
- `SYSTEM_PROMPT`: شخصیت و قوانین دستیار
- `model` و `temperature`: مدل و دمای مدل اصلی و مدل خلاصه‌ساز

## ⚠️ محدودیت‌ها و نکات امنیتی

- **ورود به سامانه احراز هویت واقعی ندارد.** در حال حاضر هر نام کاربری و رمز غیرخالی پذیرفته می‌شود. قبل از استفاده‌ی واقعی حتماً احراز هویت درست (مثلاً LDAP یا OAuth) اضافه کنید.
- پیام‌ها در Redis به‌صورت متن ساده ذخیره می‌شوند. برای داده‌های حساس سلامت روان، رمزنگاری و کنترل دسترسی ضروری است.
- کلید API را **هرگز** داخل کد یا مخزن نگذارید؛ فقط از متغیر محیطی استفاده کنید.
- این ابزار جایگزین روان‌شناس یا مشاور نیست. در شرایط بحرانی با متخصص یا اورژانس تماس بگیرید.
